# Roadmap

Buildflow's goal is to let anyone create and maintain useful local software without learning software development infrastructure.

## Now — dependable local MVP

- [x] natural language app creation
- [x] natural language modification
- [x] validation before activation
- [x] local version history and recovery
- [x] persisted data change approval
- [x] Windows installer
- [ ] first-run Codex readiness onboarding
- [ ] crash-safe resume for interrupted creation
- [ ] accessible keyboard and screen-reader audit

## Next — reach more people

- [ ] signed Windows releases
- [ ] macOS universal package
- [ ] Linux AppImage and deb package
- [ ] automatic update channel
- [ ] export and import portable project bundles
- [ ] clearer recovery diagnostics without technical jargon
- [ ] contributor development fixtures that do not require an AI account

## Later — extensible, still local first

- [ ] stable coding-agent adapter API
- [ ] opt-in additional coding agents
- [ ] reusable app recipes and local templates
- [ ] project storage location selection
- [ ] privacy-preserving opt-in quality telemetry

Cloud hosting, accounts, payments, a marketplace, and public tunnels are outside the current core scope.

Roadmap order can change based on user feedback and contributor interest. Open a discussion before starting a large item.
